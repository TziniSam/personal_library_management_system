# Personal Library Management System

## Description
This is a Python program that enables you to manage a personal library.
You can add books, borrow, return, and manage users.

## Features
- Add and delete books
- Search books by title or author
- Borrow and return books
- Manage users

## How to Run
1. Open the project in Python
2. Run the file:
   main.py
